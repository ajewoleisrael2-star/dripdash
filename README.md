# DripDash

A fashion shop with one immersive feature: AI try-on.
Built by Flexbox Pod at Webbo3 Academy, Frontend Development.

Deployed by: ajewole israel

Live site: https://ajewoleisrael2-star.github.io/dripdash/

## What it is

A plain HTML, CSS and JavaScript website. No build step: every page is a file you can open.
The data (and everything that happens when you book, buy or sign in) comes from the live
DripDash API on webbo3.com, so the site works wherever it is hosted.

## Run it on your computer

Double-click `index.html`.

## Put it online

GitHub repository, then Settings, Pages, Deploy from a branch, main, / (root), Save.
